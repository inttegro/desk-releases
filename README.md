# Inttegro Desk

Official installers for Inttegro Desk.

This repository contains release artifacts only. It does not contain application source code or accept issue reports.

## Release channels

- **Stable** releases are suitable for general use and are marked **Latest**.
- **Beta** releases are public previews and are marked as prereleases.
- **Developer** builds remain private release candidates.

## Verify a download

Every release includes a `SHA256SUMS` manifest. Inttegro Desk for macOS is signed and notarized; the Windows installer is Authenticode signed.

For product information and support, visit [inttegro.com](https://inttegro.com).
